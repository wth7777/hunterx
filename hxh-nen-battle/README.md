# Hunter × Hunter: Nen Card Battle

Browser-based card battle game — Magic: The Gathering mechanics + Hunter × Hunter characters & Nen system.

## Play

Open `index.html` in any modern browser. No install, no server required.

## What’s new in this version

- **Manual targeting** — When a Technique (or enter effect) needs a target, valid enemies / your characters / AI face glow gold. Click the one you want.
- **Upgraded graphics** — Nen-colored card borders & art backgrounds, glow effects, attack pulse, damage flash, richer UI.
- **Sound effects** — Pure Web Audio API (no external files). Toggle with the button in the top-right.
- Still a single self-contained HTML file — perfect for GitHub Pages.

## Features

- 20 life, progressive Aura resources
- Characters + Techniques with Nen affinities
- Combat (attackers / blockers)
- Deck builder (saves to localStorage)
- Easy / Medium / Hard AI

## Deploy to GitHub Pages

1. Push this folder to a repo
2. Settings → Pages → Deploy from branch (main / root)
3. Open the site URL — game runs instantly
