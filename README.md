# Hunter × Hunter: Nen Card Battle

A browser-based card battle game combining **Magic: The Gathering** combat mechanics with **Hunter × Hunter** characters, Nen affinities, and story-inspired abilities.

## How to Play

Open `index.html` in any modern browser (Chrome, Firefox, Edge, Safari). No server or install required.

### Features

- **Two-player battlefield**: You vs AI Hunter
- **20 life** each – reduce opponent to 0 to win
- **Aura resources**: Max Aura increases by 1 each turn (MTG land-style progression)
- **Character cards**: Attack / Defense, Aura cost, unique Nen abilities
- **Technique cards**: Instants, buffs, removal, healing, combat tricks
- **Nen affinities**:
  - Enhancement – heavy hits & durability
  - Transmutation – elemental tricks
  - Emission – ranged damage
  - Conjuration – chains, weapons, constructs
  - Manipulation – control & discard
  - Specialization – rule-bending powers
- **Combat**: Declare attackers → blockers → simultaneous damage
- **Deck Builder**: Build 30–40 card decks (saved in localStorage)
- **Progressive difficulty**: Easy / Medium / Hard AI with stronger decks and more aggressive play

### Characters Included

Gon, Killua, Kurapika, Leorio, Hisoka, Chrollo, Uvogin, Netero, Kite, Illumi, Shalnark, Razor, Silva, Shizuku, Neferpitou, Meruem and more techniques inspired by Hunter Exam, Heavens Arena, Yorknew, Greed Island and Chimera Ant arcs.

### Quick Rules

1. Start of turn: Aura max +1, refill Aura, untap, draw 1.
2. Main phase: Play Characters and Techniques by paying Aura.
3. Combat: Select attackers → AI (or auto) blocks → damage.
4. Characters enter with summoning sickness (except Killua’s Godspeed).
5. Win by dealing 20 damage total to the opponent.

Enjoy the hunt!
